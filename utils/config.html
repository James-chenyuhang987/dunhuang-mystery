DUNHUANG · LEVEL BUILDER

关卡配置生成器

手动填写关卡、全景、线索、谜题与球面向量，生成可以直接复制到 src/data/game.ts 的 TypeScript 对象。

关卡信息

全景图

URL 从项目根目录填写，例如 /art/cave-01.svg。紫外线地址可留空。

线索热点 · Vec3

x、y、z 直接填写球面坐标。热点会生成 vec: new Vector3(x, y, z)，不需要在本工具中点击全景图。

线索

“关联题目”填写题目在本关 problems 数组中的下标，例如 0, 2。

谜题

正确答案使用 1–4 表示，生成时会自动转换成 TypeScript 所需的 0–3 下标。

生成结果

修改字段后点击“生成配置”。
